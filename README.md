# S.O.L - Study Of Language AI

S.O.L (Study Of Language AI) is an elegant, high-fidelity language assistant web interface. Tailored with a custom premium design featuring yellow, gold, gray, white, and carbon-black color tones, it features a sliding navigation sidebar with 8 panels based on your design sketch.

It runs entirely client-side in the browser as a zero-build application, keeping all your data private and local.

## ✨ Sliding Sidebar Categories & Panels

- **🏠 Start Here**: Introduction guide to S.O.L and quick links to the tools.
- **👥 Globally Known Community**: A simulated learner community post board. Share questions and receive immediate responses/tips from the S.O.L Mentor AI.
- **🎯 Random Word Generator With Guided Pronunciation**:
  - Select from Spanish, French, German, Italian, or English.
  - Listen to native audio guided pronunciation (using browser text-to-speech).
  - Practice pronunciation by speaking directly into your microphone (using the Web Speech Recognition API).
  - Receive an accuracy matching score (e.g. 95% Match) and tips on how to improve.
  - *--- Horizontal Divider Line ---*
- **📺 Organized Comprehensible Input Videos**: Curated Youtube language lessons with transcripts and descriptions.
- **📖 The Visual Dictionary**: Search any word to analyze its roots, semantic origins, etymologies, and conceptual metaphors.
- **🎯 The Describing Lab**: Practice describing random landscapes (e.g., beach, forest, city). Submit your text to receive a grammatical audit, vocabulary enhancements, and a suggested native rewrite.
- **💬 The Output Practicing**: Dialog practice arena with specialized S.O.L agents (S.O.L General, Grammar, Translator, Vocabulary) supporting real-time streaming and code block copying.
  - *--- Horizontal Divider Line ---*
- **ⓘ Info / Settings**: Configure your Gemini API Key from Google AI Studio, clear your browser local storage cache, and view application stats.

## 🚀 Getting Started

1. **Locate the folder:**
   ```
   C:\Users\Milla\.gemini\antigravity\scratch\gemini-chat-agent
   ```
2. **Run a local static web server:**
   * **Python:**
     ```bash
     python -m http.server 8080
     ```
   * **Node (npx):**
     ```bash
     npx serve
     ```
3. **Open in browser:**
   Navigate to [http://localhost:8080](http://localhost:8080).
4. **Retrieve a Free Gemini API Key:**
   Get a key in seconds from [Google AI Studio](https://aistudio.google.com/) and paste it in the S.O.L settings (under the bottom tab ⓘ).
